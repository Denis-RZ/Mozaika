# Lite JS Demo (No Backend)

Single-page JavaScript mosaic demo for GitHub Pages.

Path:

- `docs/lite-demo/index.html`

Features:

- image upload
- field/chip/gap setup
- palette input in HEX
- max color limit
- zoom/pan on source projection
- PNG export

Run locally:

```powershell
cd docs/lite-demo
python -m http.server 8088
```

Open:

- `http://127.0.0.1:8088`

GitHub Pages:

- publish repository with `docs` as Pages source
- open `/lite-demo/`
