# План развития Mozaika (черновик)

## Цель
Собрать рабочий продукт в 3 этапа: сначала быстрый внутренний инструмент оценки, затем коммерческий кабинет заказчика, затем производственные карты для укладчиков.

## Этап 0 (сделано сейчас)
- Заархивирован legacy Python backend в `archive/backend-python-legacy-2026-02-24.zip`.
- Рабочий контур оставлен на `.NET + React`.
- Локальная SQLite база перенесена в `data/mozaika.local.db`.

## Этап 1: V1 для внутренней оценки (приоритет: максимальный)
### Что должно быть готово
- Генерация мозаики из доступных цветов и цветов затирки.
- Рабочее поле в мм/метрах, чипы квадратные (10x10 мм), шов 2 мм.
- Удобное позиционирование исходного изображения: увеличить/уменьшить/сдвинуть до и после генерации.
- Быстрый пересчет при изменении числа цветов.
- Легенда: общее число чипов, число цветов, список цветов с количеством.

### Что нужно доработать в текущем коде
- Разрешить выход мозаики за границы рабочего поля с обрезкой по рабочей зоне.
- Убрать ограничение смещений только внутри поля.
- Первую генерацию делать максимально детализированной (не `3` по умолчанию, а авто по палитре).
- Добавить действие "заменить весь цвет A на цвет B" без ручной поклеточной правки.
- Добавить zoom/pan области предпросмотра для больших форматов.

## Этап 1.5: коммерческий режим (MVP для заказчика)
### Функционал
- Авторизация и роли: `admin`, `customer`, `viewer`.
- Сущность `Project`: изображение, параметры поля, палитра, результат генерации.
- Сохранение/открытие проекта, история сохраненных генераций.
- Отправка предварительного заказа на согласование.
- Формула цены и мгновенный пересчет цены при смене числа цветов.

### Экспорт
- PNG/JPEG, SVG, PDF (печать) из сохраненного результата.
- Печатный лист с легендой материалов.

## Этап 2: производственный контур
### Функционал изготовителя
- Разбивка общей мозаики на монтажные квадраты/плитки.
- Нумерация плиток (снизу слева, слева направо).
- Координатная сетка для сборки.
- Ведомость материалов: цвет -> количество чипов.
- Режим зеркального вывода для печати схемы укладки.
- Печатные шаблоны по плиткам (PDF постранично).

## Технический план по спринтам
1. Спринт A (1-2 недели): закрыть доработки V1 по генерации/позиционированию/замене цвета.
2. Спринт B (1-2 недели): проекты + сохранение + история + базовый экспорт PNG/PDF.
3. Спринт C (1-2 недели): роли/авторизация + коммерческий сценарий заявки.
4. Спринт D (2-4 недели): производственная разбивка, карты укладки, зеркальная печать.

## Критерии готовности V1
- За 1-3 минуты пользователь получает 2-3 варианта детализации одного изображения.
- Можно вручную заменить любой используемый цвет на другой.
- Видна понятная сводка: сколько чипов, сколько цветов, как изменился результат.
- Проект можно сохранить и открыть позже.
