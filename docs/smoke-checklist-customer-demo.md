# Smoke Checklist Перед Показом Заказчику

## 1. Доступ и роли
- [ ] Вход `admin` работает, после первого входа запрашивается смена пароля.
- [ ] Вход `customer` работает, доступны генерация/проекты/экспорт.
- [ ] Вход `viewer` работает, студия в режиме просмотра, вкладка «Проекты» скрыта.
- [ ] Для `viewer` запросы к `/api/projects` возвращают `403`.

## 2. Генерация в студии
- [ ] Пошаговый блок «Как пользоваться генератором» отображается.
- [ ] При пустом исходнике шаг «Загрузите изображение» активен.
- [ ] После загрузки исходника активен шаг генерации.
- [ ] Кнопка «Сгенерировать мозаику» создает превью без перезагрузки страницы.
- [ ] Дробные значения (`4.7` и `4,7`) принимаются корректно.

## 3. Проекты и версии
- [ ] Создание проекта из сгенерированной мозаики работает.
- [ ] Сохранение новой версии в существующий проект работает.
- [ ] Открытие проекта и активация версии восстанавливают состояние студии.

## 4. Экспорт
- [ ] Экспорт PNG/JPEG/SVG/PDF работает.
- [ ] Экспорт CSV (материалы/координаты/плитки) работает.
- [ ] Экспорт «Комплект укладчика PDF» формируется на русском.

## 5. Стабильность
- [ ] `start-local.ps1` поднимает backend/frontend без ошибки старта.
- [ ] `dotnet build` проходит без ошибок.
- [ ] `npm run build` проходит и `check:ru` сообщает `OK`.
