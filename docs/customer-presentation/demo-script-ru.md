# Сценарий демонстрации (12-15 минут)

## Цель
Показать заказчику, как из изображения получается готовый комплект для согласования и сборки мозаики.

## Подготовка перед встречей
1. Запустить backend и frontend.
2. Войти под тестовым заказчиком: `customer / customer123`.
3. Открыть презентацию: `docs/customer-presentation/mozaika-presentation.html`.
4. Проверить, что доступны файлы в `docs/customer-presentation/assets`.

## План показа по шагам
1. Контекст задачи (1 минута)
Покажите рабочее поле в мм и объясните, что чипы фиксированного размера (10x10 мм), а шов задается отдельно.

2. Загрузка и позиционирование изображения (2 минуты)
Загрузите любое изображение, затем:
- двигайте его внутри поля,
- увеличьте/уменьшите масштаб,
- покажите, что часть изображения может выходить за границы с обрезкой по рабочей зоне.

3. Генерация мозаики (2 минуты)
Нажмите генерацию и покажите:
- сетку квадратных чипов,
- легенду по цветам,
- количество чипов и расчет цены.

4. Управление стоимостью через цвета (3 минуты)
Покажите 2 операции:
- уменьшение количества цветов (`max colors`) с пересчетом цены,
- ручную замену цвета по всей мозаике (например, черный -> коричневый).

5. Затирка, версии и сохранение (2 минуты)
Покажите:
- смену цвета затирки,
- сохранение проекта,
- повторное открытие сохраненной версии.

6. Экспорт и производственные документы (3-4 минуты)
Откройте из папки `docs/customer-presentation/assets`:
- `mosaic-preview.pdf` (согласование),
- `materials.csv` (ведомость материалов),
- `grid.csv` (координаты сборки),
- `assembly-kit.pdf` (комплект для укладчиков/цеха).

## Что проговорить голосом
1. "Первая генерация использует все нужные цвета из доступной палитры."
2. "Удешевление идет за счет уменьшения числа цветов без полной перерисовки вручную."
3. "Итог можно сохранять как проект, возвращаться к версиям и отправлять предварительный заказ."

## План Б (если на встрече проблемы с сетью/браузером)
1. Покажите `mozaika-presentation.html` и готовые файлы экспорта.
2. Пройдите по `demo-script-ru.md` как по сценарию.
3. После встречи отправьте ссылку/архив с папкой `docs/customer-presentation`.
