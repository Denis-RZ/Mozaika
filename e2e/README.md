# Интерактивная презентация Mozaika (Playwright)

Демонстрационный сценарий для заказчика: как пользоваться системой. Запускается в видимом браузере с замедлением действий.

## Что нужно перед запуском

1. **Backend** должен быть запущен на порту **8000** (прокси Vite смотрит на него). Из папки `backend-dotnet`:
   ```bash
   dotnet run --urls http://localhost:8000
   ```
2. **Frontend** можно не запускать вручную — Playwright при необходимости сам поднимет его по умолчанию.

## Запуск презентации

Из папки `e2e`:

```bash
cd e2e
npm install
npm run presentation
```

Откроется браузер, и сценарий по шагам покажет:

1. Открытие приложения и экран входа  
2. Вход под демо-аккаунтом (admin / admin123)  
3. Вкладка **Генерация**: выбор изображения, параметры, кнопка «Сгенерировать мозаику»  
4. Генерация мозаики (если загружен файл из `e2e/fixtures/sample.png`)  
5. Вкладка **Проекты**: список проектов  
6. Вкладка **Палитра**: цвета  
7. Блок **Экспорт и печать** на вкладке Генерация  
8. Завершение

## Опции

- **Приложение уже запущено** (например, на порту 5173):

  ```bash
  SKIP_SERVER=1 npm run presentation
  ```

- **Другой URL фронтенда**:

  ```bash
  PRESENTATION_BASE_URL=http://localhost:8080 npm run presentation
  ```

- **Запуск с UI Playwright** (пошаговый просмотр и отладка):

  ```bash
  npm run presentation:ui
  ```

## Тестовое изображение

В `e2e/fixtures/` используются:
- **sample.jpg** — нормальное изображение (320×240) для демо и генерации мозаики; при его наличии сценарий подставляет его и генерация проходит без ошибок.
- **sample.png** — запасной минимальный вариант, если `sample.jpg` нет.

Для своей демонстрации можно заменить `sample.jpg` на любое подходящее изображение.
