# Презентация Mozaika для заказчика

Презентация в формате PowerPoint (`.pptx`) с расширенным покрытием функционала системы.

## Что внутри

- 14 слайдов по ключевым блокам:
1. Титул и KPI
2. Карта функционала
3. Авторизация и роли
4. Подготовка генерации
5. Генерация результата
6. Палитра и ручные правки
7. Цена и экономика
8. Превью и контроль качества
9. Проекты и история версий
10. Шаринг и предварительный заказ
11. Управление палитрой и RAL
12. Экспорт и печать
13. Производственный комплект
14. Финал

## Команды

```bash
cd presentation
npm install
npm run generate
```

Файл появится по пути:
`presentation/Mozaika-client-presentation.pptx`

Открыть автоматически:

```bash
npm run open
```
